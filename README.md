# 00_PortalLitigante_JusBaires

Proyecto de asistente de orientación técnica para el Portal del Litigante de la Ciudad Autónoma de Buenos Aires. Su implementación en Flowise tendrá un flujo y una base de conocimiento propios.

## Primera versión propuesta

- Probar el agente en un entorno de acceso restringido.
- Responder consultas operativas con una base de conocimiento revisada y enlaces oficiales pertinentes.
- Ofrecer el canal de atención humana ante falta de evidencia, una solicitud expresa o una urgencia.
- Usar datos sintéticos para las pruebas. Mantener fuera del repositorio público los insumos internos, las credenciales y los datos personales.

La activación de canales y sistemas externos requiere definir el alcance de integración. El agente solo informará una transferencia o la creación de un ticket cuando el sistema correspondiente confirme la operación.
